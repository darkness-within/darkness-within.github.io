# Darkness Within Azeroth Adventures

Welcome to the official web platform for **Darkness Within Azeroth Adventures**, a community site dedicated to the *Darkness Within* World of Warcraft EU-Haomarush guild.

## 🌌 Overview

This website serves as the central hub for our guild's community, featuring media, announcements, membership application forms, and legal/privacy documentation.

- **Guild**: Darkness Within
- **Game**: World of Warcraft
- **Live Website**: [https://darkness-within.github.io](https://darkness-within.github.io)
- **Website Purpose**: Guild showcase, recruitment, media gallery, and legal information.

---

## 🛠️ Built With

- **HTML5**: Semantic and responsive page structure.
- **CSS3**: Custom CSS styling utilizing CSS Variables (`:root`) and dynamic flex layouts.
- **Goodmountain Font**: Custom typography created by [Hermann S Designs](https://github.com/Hermann-S-Designs/Goodmountain).
